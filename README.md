# Compatible displacement PINN for grout-vein junctions

Source code for the symmetric-cross and offset-T load-transfer problems. The
method uses shared displacement traces inside each material, finite normal and
tangential soil/grout springs, local corner and neural fields, and a constrained
joint fit of neural coefficients and moment-preserving interior fields.

All physical inputs are prescribed. Geometry, quadrature, intermediate fields,
and final fields are generated by the code; no experimental files, downloaded
datasets, or pretrained weights are needed.

## Environment

The code was checked with Python 3.13.7, NumPy 2.4.4, SciPy 1.16.2, pandas 2.3.3,
and PyTorch 2.8.0 on Windows. Computation uses CPU double precision and SciPy
LAPACK. A GPU is not used.

From the repository root:

```powershell
python -m venv .venv
.venv/Scripts/Activate.ps1
python -m pip install -r requirements.txt
```

On Linux/macOS, activate the environment with `source .venv/bin/activate`.

The final T solve assembles 262,429 rows and 3,630 neural columns: the uncompressed
double-precision matrix alone occupies about 7.6 GB. Allow at least 32 GB RAM
for matrix assembly and the dense constrained solve, and run the two T cases
sequentially. The driver defaults OpenBLAS to two threads unless the environment
already sets `OPENBLAS_NUM_THREADS`; PyTorch uses two CPU threads. Original solve
records total about 56 minutes of cross fitting and 8–16 minutes per final T fit.
Input preparation, initial T fits, and field exports add time; hardware and BLAS
implementations affect these timings.

## Reproduce the fields

```powershell
python -X utf8 scripts/reproduce.py --case all
```

Run a single geometry, inspect the exact command sequence, or resume a completed
prefix with:

```powershell
python -X utf8 scripts/reproduce.py --case cross
python -X utf8 scripts/reproduce.py --case offset-t
python -X utf8 scripts/reproduce.py --case all --list
python -X utf8 scripts/reproduce.py --case offset-t --start-at t_equal_moment_coupled
```

`--start-at` requires the earlier stages' generated files to remain in this
checkout. By default every selected stage is recomputed. Numerical errors stop
the driver and identify the failing subprocess.

The cross recipe retains the original mixed-field training that produced its
hidden features, then fits the compatible energy field, adds corner/local
enrichments, adapts the narrow local features, and adds the wide support. The
offset-T recipe generates the base/corner/local fields for both spring states,
adapts the equal-stiffness narrow-local field for 200 iterations, appends the final
support functions, and performs the two coupled solves.

For the T field, the final solve sets all readouts to zero before assembling its
affine system. Intermediate fits that change only those readouts can therefore
be omitted. `assemble_t_space` calls the existing support constructors with the
original seeds and sizes. Its options and all 97 hidden-feature/buffer tensors
were checked against the original final T space and agree exactly. It retains
3,630 neural coefficients, 466 equation moments, and 760 interior coefficients.

The source configuration is:

- `config/problem.json`: constituent properties, shortening, and cross geometry.
- `full_domain_geometry.OFFSET_T`: the prescribed offset-T rectangles and bounds.
- `config/method_study.json`: initial fields, random seeds, and cross support fit.
- `config/method_moments_full.json`: final T integration and equation control.

The specimen is 100 mm square with 0.1 mm shortening. Soil and grout Young moduli
are 79.9 and 12,700 MPa; both Poisson ratios are 0.3. Both geometries contain
1,000 mm² grout. The T pair uses `(K_n, K_t) = (10, 10)` and `(10, 1)` MPa/mm.
The soil modulus and Poisson ratio, and the 12.7 GPa grout modulus, follow
[Zhu et al. (2025)](https://doi.org/10.1038/s41598-025-24835-6). The grout Poisson
ratio, geometry, loading, and interface stiffnesses are prescribed inputs.
The input generator checks that the historical cross recipe and the prescribed
case values agree. Changing the physical problem requires updating the case
definition and training recipe together.

## Generated outputs and field loading

| Field | Generated files |
|---|---|
| Cross, narrow adapted support | `results/feasibility/partitioned_2d/cross_energy_local_adapted.{pt,json,csv}` |
| Cross, added wide support | `results/method_study/cross_additive_support.{pt,json,csv}` |
| T, equal stiffness | `results/method_study/t_equal_moment_coupled.json`, `t_equal_moment_coupled_neural.pt`, `t_equal_moment_coupled.csv` |
| T, lower tangential stiffness | `results/method_study/t_sliding_moment_coupled.json`, `t_sliding_moment_coupled_neural.pt`, `t_sliding_moment_coupled.csv` |

JSON outputs include reactions, interface resultants, regional strain averages,
section forces and grout load fractions. T result JSON files also hold the
interior coefficients. A T neural checkpoint alone is only one component of the
final field; load its JSON recipe to recover the complete displacement:

```python
import sys
from pathlib import Path
sys.path.insert(0, "scripts")

from diagnose_moment_interior import load_probe_field
from full_domain_pinn import section_readouts

model = load_probe_field(Path("results/method_study/t_equal_moment_coupled.json"))
sections = section_readouts(model, [-0.29, -0.19, 0.11, 0.21, 0.31], 256)
print(sections)
```

Keep each T JSON beside its generated neural checkpoint at the recorded relative
path. The final CSV exporter also uses this complete-field loader. Cross fields
are loaded with `partitioned_energy_pinn.load_model`.

Coordinates, displacements, stresses, and strains in field CSV files are
normalized by `H`, `Delta`, `E_s * Delta / H`, and `Delta / H`, respectively.
`gamma_xy` is engineering shear. The line-force scale is `E_s * Delta = 7.99`
N/mm per unit thickness. JSON readouts label dimensional values explicitly and
otherwise provide the scales used to convert normalized values.

The equation-controlled neural field and the fixed-neural interior correction
can also be regenerated from the prepared T space:

```powershell
python -X utf8 scripts/refit_traction_control.py results/method_study/t_final_trial_space.pt --output results/method_study/t_equal_moments_full
python -X utf8 scripts/diagnose_moment_interior.py results/method_study/t_equal_moments_full.pt --output results/method_study/t_equal_moment_interior
```

## Verification

```powershell
python -X utf8 scripts/reproduce.py --stage inputs
python -X utf8 -m unittest discover -s scripts -p "test_*.py" -q
```

The 32 tests exercise constitutive and corner derivatives, energy fitting,
finite-interface residuals, equation moments, the independent interior
elimination versus a direct constrained solution, and complete-field checkpoint
replay. Preparation produces 20 T cells, eight material corners, and the
prescribed 1,000 mm² grout area. These checks and the entry command inspection
were performed in this standalone checkout. The full production training chain
was not rerun while preparing this release; the original settings and generators
are provided above. Floating-point and optimizer differences across numerical
libraries can change the recomputed values.

Generated `data/`, `results/`, weights, logs, and caches are ignored by Git.
